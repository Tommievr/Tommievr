# Background prompt template (v1.1: simple, bold, clean 3D cartoon)
Per-location, ready-to-paste versions are in `../backgrounds/prompt-packs/`. This is the generic template:

"Simple bold stylized 3D cartoon background, [LOCATION]: [MUST-HAVES]. Flat clean saturated colors, big simple soft shapes, minimal detail, NO texture noise, NO realistic detail, NO characters, NO text, empty open lower third for characters, accent colour [ACCENT HEX], palette [PALETTE]. [DAY | GOLDEN HOUR | DUSK light line]. Wide 16:9."

Light lines: DAY = bright clear blue sky, white-cream clouds, short shadows · GOLDEN HOUR = warm golden-hour light, low sun, peach horizon, long soft plum shadows · DUSK = indigo sky fading to apricot and rose, calm, tiny warm lights.
Variants: add "layered: separate sky / far / mid / ground / foreground" if the tool supports it; "vertical 9:16, taller sky, centred composition" for Shorts.
Log each accepted result (tool, settings, seed) next to the image so it can be reproduced.
