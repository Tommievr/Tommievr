# Meshy master guide (v1.1: stylised 3D cartoon, simple fur)
Ready-to-paste prompts per character are in **`characters/evie.md`, `justin.md`, `cotton.md`, `toffee.md`** (generated by `tools/build_prompt_packs.py`).
This file = shared rules + the **step-by-step "what to click"**. Fixing bad results: `QA_AND_FIXES.md`. Day-1 order: `../DAY1_CHECKLIST.md`.

> **Untested warning.** The cloud design session cannot run Meshy or an image generator, so no prompt here has been run yet. Meshy renames buttons often: ⚠ = check on the day. Log every accepted result (`pipeline/meshy/<name>/raw/LOG.md`: date, plan, tool, seed, settings, prompt).

## 1. The style words (why the prompts look the way they do)
Meshy and image models default to realistic fluffy fur, which gives noisy geometry and a look Tommie does not want. Every prompt therefore says:
**"stylized 3D cartoon character, chunky toy-like vinyl figure, smooth short matte fur, simple rounded shapes, very big glossy eyes, clean flat bright saturated colors, soft toon shading"**, and the negatives forbid **fur strands / hair / fuzzy / photorealistic / Pixar fur / detailed texture**. Lambs say **"big simple rounded cloud clumps (no curls)"**.
If a result still looks furry: add "smooth plastic toy" / "clay figure" and re-roll; do not describe fur.

## 2. Shared settings (summary; full tables are in each character file)
| Setting ⚠ | Value |
|---|---|
| Mode | Image-to-3D (multi-image front+side+3/4 if offered), text-to-3D as fallback |
| Art style (text mode) | Cartoon |
| Topology | Quad; target **30,000** polys (20k-50k range) |
| Symmetry | On |
| Pose | None (neutral standing on four legs is in the image/prompt) |
| Texture | On; base colour only matters; **no baked light** (de-light if offered) |
| Export | GLB |
| Commercial rights | **Confirm the plan's licence before publishing anything**; record plan + date in `pipeline/meshy/LICENCE_NOTES.md` |

## 3. Step-by-step: what to click (Evie as the example; repeat per character)
1. **Prepare the folder:** `pipeline/meshy/evie/raw/` (inputs + outputs + `LOG.md`).
2. **Make the front image:** open your image tool (ChatGPT / Gemini / Midjourney / Flux). Crop Evie from `assets/characters/evie-and-justin-reference.png`. Upload it and paste prompt **A1 (restyle)** from `characters/evie.md`. Generate 4. Pick the one that looks like a simple chunky toy with the right colours and the patch top-left. Save `evie_front.png`. *If it still looks furry/realistic, repeat A1 with "smooth plastic toy figure" added.*
3. **Make side and 3/4 images:** upload the chosen front image as reference, paste **A2 SIDE**, then **A2 THREE QUARTER** prompts. Generate 4 each; pick; save `evie_side.png`, `evie_34.png`.
4. **Check each image** with the input checklist (section 4 below). Fix the image, not the 3D.
5. **Open Meshy** (meshy.ai, logged in on the paid plan) → **Workspace** → choose **Image to 3D** ⚠ (or "Multi-view / Multi-image to 3D").
6. **Upload** `evie_front.png` (and side/3-4 in the extra slots if offered).
7. **Set the options** from the table in `characters/evie.md` section B: Topology Quad, Polycount 30000, Symmetry On, Pose none, Texture on.
8. Click **Generate** ⚠. Wait. A preview model appears. **Orbit it**: front, side, back, top. Look at the legs, tail, ears, face.
9. If good: use **Retexture** ⚠ only if the colours are off (paste section D). If bad: **re-roll** (Regenerate, new seed) up to 4 times, then fix the input image or use the text-to-3D fallback (section C).
10. **Download:** format **GLB**; save as `pipeline/meshy/evie/raw/evie_v1.glb`. Also note the seed/model name in `LOG.md`.
11. **Automatic QA in Blender:** `blender -b --python pipeline/blender/qa_model.py -- pipeline/meshy/evie/raw/evie_v1.glb --shot pipeline/meshy/evie/raw/qa.png`, then work through `QA_AND_FIXES.md`.
12. **PASS?** Continue with `../blender/SETUP.md` (clean, toon material, rig). **FAIL?** Use the fix-it table, or regenerate.

## 4. Input-image checklist (per image, before uploading)
- [ ] One character, full body, centred, ~10 % margin, square
- [ ] **Simple chunky toy look: no fur strands, no fuzz halo, no fine texture**
- [ ] Mouth closed; eyes open and symmetric
- [ ] Four paws visible and separated; tail clearly visible (cats) / pom visible (lambs)
- [ ] Neutral even light; no golden tint, rim glow or cast shadow
- [ ] Collar and tag/bell visible, centred, facing the camera
- [ ] Colours match the base hexes in the character sheet; markings correct
- [ ] No text, props or second character

## 5. Prompt cheat-sheet (if you must write your own)
`[chibi kitten | baby lamb], stylized 3D cartoon character, chunky toy-like figure, [smooth short <colour> fur | <colour> wool made of big simple rounded cloud clumps], very big glossy [colour] eyes, [markings], [collar colour] collar with round gold [paw-print tag | heart-slot bell], short stubby legs, [fat curled tail | small round pom tail], standing on four legs, neutral pose, closed mouth, matte clean flat colors, game-ready`
Always add the negative prompt from the character files.
