# Script Writers Channel

Welcome! You write the adventures of **Evie** (white, dreamer) and **Justin** (black, explorer).
Read first: `../lead/CHANNEL_BIBLE.md` and `../lead/CHARACTERS.md`.

## How to work
1. Pick an episode from `../lead/episodes/EPISODE_SLATE.md`.
2. Put sourced facts in `research/ep0X-<slug>.md`.
3. Copy `EPISODE_TEMPLATE.md` to `scripts/ep0X-<slug>.md` and draft.
4. Copy `SHORT_TEMPLATE.md` for the 3 promo shorts into `shorts/`.
5. Set `status:` in the file header: `draft → ready-for-review → approved`.
6. Questions or canon changes → add to `NOTES.md`; the lead answers.

## Hard limits
- Episode: **≤ 10:00** (~1,300 words of dialogue at calm pace plus action beats).
- Short: **20–45 s** (~60–110 words).
