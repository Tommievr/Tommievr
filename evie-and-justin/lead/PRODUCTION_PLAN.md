# Production Plan (hardware day)

## Goal
Get 7 episodes + 21 shorts through a repeatable pipeline.

## Pipeline
1. **Script** (writers) → lead approval
2. **Storyboard / shot list** (per scene, 3–6 s shots)
3. **Character-consistent image/video generation** using the reference art (lock eye colours, collars, markings)
4. **Voices** (Evie / Justin / narrator) — record or synthesize; keep voices consistent across episodes
5. **Assembly + sound** (music, ambience, Foley) in an editor
6. **Shorts cut-down** → vertical 9:16 reframing
7. **QA**: facts, character consistency, kid-safety, ≤10:00

## Open decisions for tomorrow
- What hardware (GPU/VRAM) and which generation tools/models will be used?
- Voice approach: human voice actors vs. synthetic?
- Real Dutch location footage/photos as backgrounds vs. fully generated worlds?
- Channel name, logo, upload account.

## Suggested order
Do Episode 1 end-to-end first as the pipeline proof, then batch the rest.
